# DATA CLEANING & EXPLORATORY DATA ANALYSIS

## Clinic Appointments Dataset

A beginner-friendly data analytics project focused on cleaning, preprocessing, exploring, and visualizing clinic appointment data using Python.

## 📌 Project Overview

This project analyzes a clinic appointments dataset containing information about patients, doctors, departments, appointment dates, billing amounts, follow-up requirements, and appointment waiting times.

The project was developed as part of a **Data Analytics Internship project at CodSoft**.

## 🎯 Project Objectives

* Clean and preprocess the clinic appointment dataset
* Identify missing values and duplicate records
* Analyze data types and dataset structure
* Perform statistical analysis
* Explore patient demographics
* Analyze appointment trends
* Analyze billing patterns
* Compare departments and doctors
* Analyze follow-up requirements
* Identify meaningful business insights through data visualization

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook
* Anaconda

## 🧹 Data Cleaning & Preprocessing

The following preprocessing tasks were performed:

* Loaded the dataset using Pandas
* Inspected rows, columns, and data types
* Checked for missing values
* Checked for duplicate records
* Reviewed statistical summaries
* Converted appointment and booking dates into datetime format
* Created age groups for analysis
* Prepared the cleaned dataset for Exploratory Data Analysis

## 🔍 Key Findings

* The dataset contains **1,000 appointment records**.
* The average patient age is approximately **53.75 years**.
* Female patients represent **52.7%**, while male patients represent **47.3%**.
* **Neurology** recorded the highest appointment volume.
* **Jennifer Adams** had the highest number of appointments.
* The **General department** had the highest average billing amount at approximately **290.19**.
* The average billing amount was approximately **275.80**.
* **51.4%** of appointments required follow-up.
* The average booking-to-appointment waiting time was approximately **274.56 days**.
* The maximum waiting time was **728 days**.
* **October 2025** recorded the highest appointment volume based on the appointment-month analysis.
